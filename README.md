# RecruitSmart CRM

Portfolio case study of an HR-tech system for high-volume recruiting.

RecruitSmart helps recruiting teams process candidate demand faster, keep the
funnel visible, reduce repetitive communication work, and measure operational
bottlenecks.

## Product focus

- candidate intake through web and messaging channels;
- recruiter workspace with pipeline, communication and scheduling tools;
- automated reminders and operational workflows;
- measurable funnel, response-time and workload indicators;
- AI-assisted features with data-minimization boundaries.

## Architecture

The product follows a modular-monolith approach with separate background
workers. Its main technology contour includes Python, React, PostgreSQL, Redis,
Docker and messaging-platform integrations.

This public repository is a sanitized portfolio presentation. It does not
contain production source code, deployment manifests, infrastructure topology,
credentials, candidate data, private runbooks, or security audit materials.

See [the case study](docs/CASE_STUDY.md) for the product problem, approach and
measurable outcomes.
